# Repository Guidelines

Web INSIGHT is a **level studio**; the shipped game is the Android app in `../project-insight-android`. See `README.md` for the workflow and `editor.md` for studio controls.

## Structure

`index.html` and `Editor.html` open the studio (`src/EditorApp.jsx`, `src/useEditor.js`); `Puzzle.html?editor=1` is the playtest screen (`src/GameApp.jsx`, `src/useGame.js`, `src/game-state.js`) and redirects to the editor when no validated puzzle was handed over. `src/puzzle-rules.js` and `src/puzzle-solver.js` are shared with Node checks and the editor worker. `src/data/` holds the levels; `scripts/studio-plugin.mjs` is the dev-server "Add to game" endpoint. Reuse `legalMoves`, `swapCells` and `startPuzzle`.

## Commands

`npm run dev` (127.0.0.1:8000), `npm run build`, `node scripts/check-levels.cjs [--game 2|3] [--update]`, `node scripts/check-editor.cjs`, `node scripts/check-react.cjs`. Run the browser checks after `npm run build`; they need Playwright and Chrome. After adding levels run `./gradlew testDebugUnitTest` in the Android project.

## Rules for level data

- Levels are append-only. Android and the old web campaign key progress by 1-based level position, so never insert, reorder or delete levels in `levels.js`, `levels-2.js` or `levels-3.js`. Bump a level's `revision` when its board changes so saved attempts invalidate.
- `par` and `level-solutions*.js` are generated by `check-levels --update` or by "Add to game". Never hand-edit them. Never trust imported par/solution data: the solver re-verifies (bounded search; hitting the bound means unverified, not unsolvable).
- Studio levels are written only through the endpoint, which validates strictly, re-solves, rejects duplicates, accepts same-origin loopback requests only, and exists in `vite serve` only (not in builds).

## Style

React JSX, CSS and JavaScript with two-space indentation; `camelCase` functions, uppercase constants, kebab-case CSS classes. Preserve element IDs and tile codes. Keep drafts and playtest attempts in their own `insight-editor-*` storage keys. Use `useFeedback`/`FeedbackUI` instead of browser alert/confirm. No formatter or linter is configured.
